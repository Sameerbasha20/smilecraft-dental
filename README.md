# 🦷 SmileCraft Dental Clinic

A full-stack dental clinic website built with Next.js and Supabase.

## 🚀 Features
- Multi-step appointment booking system
- Dynamic services pages
- Blog system
- Contact page with Google Maps
- Responsive UI with animations
- Supabase database integration

## 🛠 Tech Stack
- Next.js 16
- Tailwind CSS
- Supabase
- Framer Motion
